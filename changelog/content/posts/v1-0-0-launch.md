This is a sample changelog entry. It carries the `changelog` tag, so it
renders in the `/changelog` timeline and this template's own
`BlogPosting` and `BreadcrumbList` JSON-LD for that section, rather than
under `/blog`.

The leading `v1.0.0` in the title is parsed as an optional version
label; a changelog entry with no leading version number still works
fine, it just has no version chip.

Delete this file, or leave it as a working example while you connect
your first scatterpost workspace to this site.
